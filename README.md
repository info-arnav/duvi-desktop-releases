# Duvi for Mac

Signed and notarized downloads of Duvi for macOS 13.1 or later, for Apple silicon and Intel.

Download the latest `Duvi_X.Y.Z.dmg` from [Releases](https://github.com/info-arnav/duvi-desktop-releases/releases/latest), open it, and drag Duvi to Applications. Duvi updates itself from here.

This repository only holds releases. Each one is built, signed, notarized and published automatically when a version is tagged.
